System Purpose

DIMS is the governed integrated management and operating system underneath DOME. DOME is the everyday operating environment through which the user works. The current architecture separates everyday modules, cross-system intelligence/governance, and system-guard/operator functions so that older construction-era concepts do not compete with the eight primary modules.
