# MED™ User, Counselor & Administrator Guide v1.0

**Lineage:** DOME™ → EKKLĒSIA™ → Marriage & Family → Marriage1st™ → MED™ — Marriage Evaluation Dome  
**Method:** RAD™ / IAM — Identify • Assess • Mitigate  
**Governing framework:** Genesis 2:18, 21–24; Matthew 19:4–8; Ephesians 5:33

## 1. Purpose

MED™ is a private, behavior-based pastoral marriage assessment and counselor-guided reporting workflow. Husband and Wife complete their assessments independently. RAD™ scoring, spouse-to-spouse raw answers, discrepancy analysis, preliminary algorithmic conclusions, and safety-sensitive review remain counselor-only unless the counselor deliberately incorporates appropriate information into the released couple report.

MED™ is a pastoral triage and discussion aid. It is not a medical or mental-health diagnosis.

## 2. Husband / Wife Instructions

### Sign in and complete the assessment
1. Open the secure MED™ case link supplied by the counselor or administrator.
2. Sign in with the MED™ account assigned to you.
3. Confirm that the page identifies your private Husband or Wife flow and the correct instrument version.
4. Answer every governed question independently. Do not coordinate answers with your spouse.
5. For each question, answer both **How often?** and **Impact on the marriage**.
6. Select **Save securely**. A completed assessment should show the full question count as answered.

### What happens after completion
Completing the assessment does **not** immediately publish results to either spouse. MED™ analyzes the governed assessment for the authorized counselor. The counselor reviews the private analysis, edits the proposed mitigation/action guidance, and decides what is appropriate for the couple-facing report.

Until a report is released, the secure case displays **Counselor Review in Progress**.

### How to receive the report
The report itself should remain inside the secure MED™ case rather than being placed in ordinary email. A notification may tell you that the report is ready, but sensitive report content should not be included in the notification.

When the counselor releases the report:
1. Return to the same secure MED™ case link.
2. Sign in with your assigned account.
3. Find **Report Available**.
4. Open the counselor-approved **MED™ Marriage Evaluation Report**.

The couple-facing report does not expose the other spouse's raw answers, hidden RAD™ score rows, private counselor notes, or counselor-only safety details.

## 3. Counselor Instructions

### Review the private analysis
After both spouses complete the assessment, sign in with the authorized Counselor account. Review:
- completion status for Husband and Wife;
- seven-domain patterns;
- RAD™ Risk Assessment Code results;
- Husband/Wife discrepancies;
- safety-sensitive disclosures and overrides;
- priority counseling areas.

Raw assessment evidence and safety review are counselor-first and must not be treated as an automatically publishable couple report.

### Prepare the couple report
In **MED™ Report Lifecycle**:
1. Select **Generate / Refresh Draft**.
2. MED™ creates an algorithm-assisted draft from the governed case scoring.
3. Read the entire draft.
4. Edit wording, recommendations, biblical guidance, mitigation steps, and follow-up instructions as pastoral judgment requires.
5. Remove anything that should remain counselor-only.
6. Select **Save Draft** when additional review is needed. A saved draft remains private.

### Approve and release
When the report is ready:
1. Re-read the exact couple-facing text.
2. Select **Approve & Release Report**.
3. Confirm the release.
4. MED™ stores the counselor report and a separate released copy for the couple.
5. Husband and Wife can then sign back into the secure case and see **Report Available**.

Release is an explicit counselor action. MED™ must never automatically publish a preliminary algorithmic draft.

## 4. What the Couple Report Should Contain

The released report should normally contain:
- MED™ instrument/version identification;
- Marriage1st™ / RAD™ / IAM context;
- seven-domain summary;
- strengths to preserve;
- counselor-approved priority growth areas;
- counselor-approved mitigation/action plan;
- appropriate biblical foundation;
- next steps and follow-up/reassessment plan.

It should normally exclude raw spouse answers, hidden scoring rows, private counselor notes, algorithm-debug information, and safety details that require private handling.

## 5. Safety-Sensitive Results

Safety overrides take priority over ordinary couple scoring. A safety-sensitive disclosure should be reviewed privately by the counselor before ordinary joint discussion. The generated draft is not authority to disclose protected or potentially dangerous information to the other spouse. The counselor determines appropriate pastoral handling and, when necessary, referral to qualified professional or emergency resources.

## 6. Administrator Instructions

The administrator manages governed MED™ access and case assignments. Administrator responsibilities include:
1. Create or provision authorized MED™ users through the existing MED administrator console.
2. Assign exactly the intended Husband, Wife, and Counselor to the case.
3. Confirm the correct MED™ instrument version is bound to the case.
4. Do not expose spouse responses or counselor-only scoring while troubleshooting access.
5. Use the report lifecycle as designed; do not bypass counselor approval by manually exposing draft or private report records.

Administrators may have elevated diagnostic access, but elevated access does not change the confidentiality model of the couple-facing report.

## 7. MED™ Report Statuses

**Assessment in Progress** — spouse has not completed all governed questions.  
**Counselor Review in Progress** — assessment data exists, but no couple-facing report has been released.  
**Draft Saved** — counselor has saved a private report draft.  
**Approved / Released** — counselor explicitly approved a report version and released it to the couple.  
**Report Available** — Husband and Wife may sign in and view the released version.

## 8. Report Lifecycle

**Assessment → Analysis → Counselor Review → Mitigation Plan → Approval → Release → Couple Review → Follow-Up → Reassessment**

This lifecycle implements IAM as a pastoral workflow:
- **Identify:** recognize strengths, patterns, discrepancies, risks, and safety concerns.
- **Assess:** evaluate frequency/probability, impact/severity, RAC, and domain patterns.
- **Mitigate:** counselor reviews and approves actions intended to eliminate, reduce, control, monitor, or responsibly manage identified concerns.

## 9. Privacy Rule

A spouse's permission to view a released couple report is not permission to view the other spouse's private assessment record. The released report is a separate counselor-approved artifact with its own access boundary.
