Risk Assessment Dome

The governed DOME guide for assessing risk, sequencing executable work, and prioritizing the abatement of actual physical hazards. RAC, EPI, and APN are related controls, but they answer different management questions.

RAC — Assess RiskSeverity × Probability. RAD uses RAC as a risk-assessment control for physical and non-physical governed conditions. EPI — Prioritize DIMS ExecutionDetermines relative execution order after governance/readiness gates using the governed DEA execution criteria. APN — Prioritize Physical Hazard AbatementActual physical hazards only. Used when personnel exposure and abatement cost are meaningful safety, fire, or occupational-health inputs.

1. RAC — Risk Assessment Code

RAD™ uses the familiar Severity × Probability approach to characterize risk. In DIMS, RAD is the broader cross-system risk-assessment service; it can support governed assessment of both physical and non-physical conditions. The System RAC remains authoritative unless changed through the governed process.

2. EPI — Execution Priority Index

EPI is a DIMS execution-priority methodology, not an Air Force formula. Its purpose is to support DEA™ in recommending the order in which executable projects and tasks should be worked. Priority expresses importance; DEA recommends sequence.

EPI / DEA sequencing = governed gates + execution factors
No certified final numerical EPI weighting formula has been approved yet.

Governed execution criteria

Urgency / Time Criticality
How quickly action is required.
Dependency / Unlocking Power
What downstream work this item enables or blocks.
Mission Impact
The breadth and importance of the effect on the mission/system.
Consequence of Delay
What worsens, fails, or is lost if action is postponed.
Readiness / Executability
Whether the work can actually be performed now after required gates.
Leverage / Return on Effort
The value or improvement produced relative to the execution burden.
Continuity / Finish What We Started
Whether completing in-progress work preserves momentum and closes loops.
Current governance: weights and breakpoints remain provisional until tested against representative live DIMS workload. The guide therefore does not invent or display a false final EPI score.

4. APN — Abatement Priority Number

APN applies to actual physical hazards only. In DIMS/RAD, use APN for physical occupational-safety, fire, or occupational-health hazards requiring abatement prioritization. Do not use APN for ordinary software, project, administrative, governance, deployment, workflow, or other non-physical DIMS risk.

APN combines the hazard RAC with a Cost Effectiveness Index (CEI) to compare abatement actions within the same RAC.

CEI = C ÷ (M × E)
APN = RAC (CEI)
M — MultiplierDerived from the same physical-hazard Severity/Probability used for the RAC.
E — Personnel ExposureAverage number of personnel exposed daily during the year.
C — Abatement CostTotal physical-hazard abatement project cost using the best available estimate.

Physical-hazard APN example: Severity II + Probability B gives RAC 2 and M = 21. If E = 25 personnel/day and C = $2,100, then CEI = 2,100 ÷ (21 × 25) = 4. Therefore APN = 2(4).
Priority rule: APNs are not used to compare hazards of different RACs. Compare CEI only within identical RACs; lower CEI means higher relative abatement priority within that RAC.

5. Quick Decision Guide

Need to assess a risk?Use RAD/RAC: Severity × Probability.
Need to decide what DIMS work goes first?Use DEA/EPI: gates plus Urgency, Dependency, Mission Impact, Consequence of Delay, Readiness, Leverage, and Continuity.
Need to prioritize correction of an actual physical hazard?Use APN only when physical hazard RAC, personnel exposure, and abatement cost apply.

DEA/EPI criteria are taken from the current DIMS DEA design, which remains prototype/not yet certified. RAD/APN boundary follows the approved DIMS clarification that APN is reserved for actual physical occupational-safety, fire, and occupational-health hazards.
